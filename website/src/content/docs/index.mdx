## What is Aquamarine?

Aquamarine is the **client runtime** for Beryl-style WebSocket channels in
Gleam. It owns the lifecycle — connecting, joining a topic, heartbeats,
ref counting, and orderly shutdown — and delegates the on-the-wire format
to a pluggable [`Codec`](/guides/codecs/) so the runtime stays separate
from protocol-specific frames.

The bundled [`aquamarine/phoenix`](/guides/phoenix/) codec speaks the
Phoenix Channels protocol, so Aquamarine talks to
[Beryl](https://github.com/tylerbutler/beryl) servers and to vanilla
Phoenix Channels endpoints out of the box.

## API shape

Four functions, one `case`: connect to a Phoenix-compatible endpoint and
handle failures through the same typed error surface used by every public
operation.

```gleam
import aquamarine
import aquamarine/phoenix
import gleam/io
import gleam/json

case aquamarine.connect(
  host: "localhost",
  port: 4000,
  path: "/socket/websocket",
  topic: "room:lobby",
  payload: json.object([]),
  codec: phoenix.codec(),
) {
  Ok(channel) -> {
    // ... use the channel ...
    let _ = aquamarine.close(channel)
    Nil
  }

  Error(error) -> {
    // See the Error handling guide for each AquamarineError variant.
    io.debug(error)
    Nil
  }
}
```

See [Error handling](/guides/error-handling/) for the
`AquamarineError` variants returned by `connect`, `push`, `receive`, and
`close`.

  <section className="aqua-section">
    <h2>One actor, five moving parts</h2>
    <p className="aqua-copy">
      The public API stays small because the socket actor handles the
      recurring channel work after the connection opens.
    </p>
    <ol className="aqua-lifecycle" aria-label="Aquamarine channel lifecycle">
      <li className="aqua-lifecycle__step">
        <code>connect</code>
        <strong>Open and join</strong>
        <span>Start the WebSocket, send the join frame, and wait for the matching reply.</span>
      </li>
      <li className="aqua-lifecycle__step">
        <code>refs</code>
        <strong>Count in order</strong>
        <span>Refs are minted inside the actor, in the handler that sends the frame carrying them.</span>
      </li>
      <li className="aqua-lifecycle__step">
        <code>heartbeat</code>
        <strong>Keep the connection alive</strong>
        <span>A timed self-message, running for the life of the socket rather than per channel.</span>
      </li>
      <li className="aqua-lifecycle__step">
        <code>push / receive</code>
        <strong>Move application frames</strong>
        <span>Inbound frames route by topic; replies correlate back to the push that asked.</span>
      </li>
      <li className="aqua-lifecycle__step">
        <code>reconnect</code>
        <strong>Come back on its own</strong>
        <span>A dropped connection retries on a backoff and rejoins every topic. Your handles stay valid.</span>
      </li>
    </ol>
  </section>

```gleam
import aquamarine
import aquamarine/phoenix
import aquamarine/transport
import gleam/json

case aquamarine.connect(
  scheme: transport.Ws,
  host: "localhost",
  port: 4000,
  path: "/socket/websocket",
  topic: "room:lobby",
  payload: json.object([]),
  codec: phoenix.codec(),
) {
  Ok(channel) -> {
    // Push, receive, and close with the same Channel handle.
    use_channel(channel)
    Nil
  }

  Error(error) -> handle_connect_error(error)
}
```

See [Error handling](/guides/error-handling/) for the
`AquamarineError` variants returned by `connect`, `push`, `receive`, and
`close`.

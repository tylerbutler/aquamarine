    </p>
  </section>

  <section className="aqua-section">
    <h2>One channel, five moving parts</h2>
    <p className="aqua-copy">
      The public API stays small because Aquamarine handles the recurring
      channel work after the socket opens.
    </p>
    <ol className="aqua-lifecycle" aria-label="Aquamarine channel lifecycle">
      <li className="aqua-lifecycle__step">
        <code>connect</code>
        <strong>Open and join</strong>
        <span>Start the WebSocket, send the join frame, and wait for the matching reply.</span>
      </li>
      <li className="aqua-lifecycle__step">
        <code>refs</code>
        <strong>Count in order</strong>
        <span>A small actor issues monotonic refs for pushes and heartbeats.</span>
      </li>
      <li className="aqua-lifecycle__step">
        <code>heartbeat</code>
        <strong>Keep the channel alive</strong>
        <span>The heartbeat actor uses the same codec boundary as the rest of the runtime.</span>
      </li>
      <li className="aqua-lifecycle__step">
        <code>push / receive</code>
        <strong>Move application frames</strong>
        <span>Outbound events are encoded; inbound noise and heartbeat replies are filtered.</span>
      </li>
      <li className="aqua-lifecycle__step">
        <code>close</code>
        <strong>Clean up actors</strong>
        <span>Shutdown stops the heartbeat and ref counter before closing the socket.</span>
      </li>
    </ol>
  </section>

  <section className="aqua-section">
    <h2>Four functions, one typed error surface</h2>
    <p className="aqua-copy">
      Connect to a Phoenix-compatible endpoint and handle failures through the
      same <code>AquamarineError</code> variants returned by every public
      operation.
    </p>
  </section>
</div>

```gleam
import aquamarine
import aquamarine/phoenix
import gleam/json

case aquamarine.connect(
  host: "localhost",
  port: 4000,
  path: "/socket/websocket",
  topic: "room:lobby",
  payload: json.object([]),
  codec: phoenix.codec(),
) {
  Ok(channel) -> {
    // Push, receive, and close with the same Channel handle.
    use_channel(channel)
    Nil
  }

  Error(error) -> handle_connect_error(error)
}
```

See [Error handling](/guides/error-handling/) for the
`AquamarineError` variants returned by `connect`, `push`, `receive`, and
`close`.
